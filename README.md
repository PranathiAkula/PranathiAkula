## 📌 Featured Projects

### ⚡ Residential Electricity Data Pipeline — EIA API
(https://github.com/pranat-analyst/Residential_Electricity_Data_Pipeline_EIA)

**Overview**  
Designed and developed an end-to-end data pipeline to extract, transform, validate, and analyze U.S. residential electricity consumption data using the U.S. Energy Information Administration (EIA) API.

The project focuses on building a reliable data workflow that transforms raw API responses into structured, analytics-ready datasets for downstream analysis and forecasting use cases.

**Problem I Explored**  
Public data sources often provide valuable information but require proper extraction, cleaning, validation, and structuring before they can support reliable analytics. This project explores building a repeatable workflow for turning raw external data into trusted datasets.
